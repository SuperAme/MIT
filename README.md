# MiBancaApp
An iOS project based on a technical test.

# Description
<p>This is a iOS Project to show a login with a section to register cards, see movements and pay cards.</p>

# Getting started
<p>
1. Make sure you have the Xcode version 16.2 or above installed on your computer.<br>
2. Download or clone the MiBanca project files from the repository.<br>
3. Review the code and make sure you understand what it does.<br>
4. Enjoy!

#Architecture
* The MiBanca project is implemented using the Model-View-ViewModel (MVVM) pattern with clean architecture.
